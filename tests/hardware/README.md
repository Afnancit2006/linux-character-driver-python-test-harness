# Hardware Test Evidence

This directory will contain on-target procedures and evidence only after a specific Linux board and GPIO input circuit are selected.

Each future test record should include:

- board, SoC, kernel, device-tree, and wiring details;
- safe input voltage and trigger source;
- exact build/load commands;
- event count, timestamps, and relevant kernel/user-space logs;
- cleanup steps and known limitations.

There is currently no hardware test evidence.
